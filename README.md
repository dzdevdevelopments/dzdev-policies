# dzdev-policies

Repositório público de políticas legais dos apps DZDEV, publicado via GitHub Pages.

## GitHub Pages

1. Repositório público: `dzdevdevelopments/dzdev-policies`
2. Settings → Pages → Source: branch `main`, folder `/ (root)`
3. URL base: https://dzdevdevelopments.github.io/dzdev-policies/

## Visão Quina

- Arquivo: `visao-quina/privacy-policy.html`
- URL Play Console: https://dzdevdevelopments.github.io/dzdev-policies/visao-quina/privacy-policy.html

## 10Dobra Loterias

- Pasta: `10dobra-loterias/`
- Arquivo: `10dobra-loterias/privacy-policy.html`
- Hub: `10dobra-loterias/index.html`
- URL Play Console: https://dzdevdevelopments.github.io/dzdev-policies/10dobra-loterias/privacy-policy.html

### Como atualizar

1. Edite o HTML correspondente em `10dobra-loterias/`.
2. Atualize a data de vigência no topo da política.
3. Faça commit e push na branch `main`.
4. Aguarde a publicação do GitHub Pages (source: `main`, pasta `/`).
